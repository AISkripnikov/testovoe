# Мои финансы — Android

Приложение само записывает доходы и расходы по карте **ВТБ**: читает push-уведомления
ВТБ Онлайн и SMS от `VTB`, определяет сумму, тип операции, магазин и категорию.
Всё хранится только на телефоне, разрешения на интернет у приложения нет.

## Возможности

- Автоматическая запись операций из уведомлений и SMS ВТБ; дубли (push + SMS об одной покупке) отбрасываются
- Загрузка старых SMS от ВТБ — сразу видна история за прошлые месяцы
- Автокатегории по названию магазина (Пятёрочка → Продукты, Яндекс Такси → Транспорт и т.д.)
- Приложение запоминает исправления: поменяли категорию у магазина — дальше он всегда будет в ней
- Итоги по месяцам, расходы по категориям, список операций по дням
- Ручное добавление, редактирование и удаление операций
- Экспорт в CSV (открывается в Excel)
- Журнал нераспознанных сообщений банка и проверка распознавания произвольного текста

## Установка

1. Скачайте `app-release.apk` на телефон и откройте его. Разрешите установку из этого источника.
2. Откройте «Мои финансы» → ⚙ (Подключение ВТБ).
3. **Уведомления ВТБ Онлайн** → «Открыть настройки» → включите «Мои финансы».
   Если переключатель серый («Ограниченная настройка», Android 13+):
   «О приложении» → ⋮ → «Разрешить ограниченные настройки», затем повторите.
4. **SMS** → «Разрешить SMS» → старые SMS от VTB загрузятся автоматически.
5. В приложении ВТБ Онлайн должны быть включены push-уведомления об операциях.

## Если что-то не распознаётся

ВТБ периодически меняет текст уведомлений. Всё, что приложение не смогло разобрать,
попадает в «Нераспознанные сообщения» (⚙ внизу). Нажмите на сообщение, чтобы скопировать,
и пришлите — правило добавляется в `VtbParser.kt`, плюс тест в `VtbParserTest.kt`.

## Сборка

```bash
cd android
./gradlew testDebugUnitTest assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

Нужны JDK 17+ и Android SDK (platform 35). GitHub Actions собирает APK на каждый push
(вкладка Actions → артефакт `MyFinance-apk`).

Ключ подписи `keystore/app.jks` (пароль `android`) лежит в репозитории специально —
чтобы новые версии ставились поверх старых без потери данных. Он не секретный.
