# Мои финансы

Простое веб-приложение для учёта доходов и расходов (Flask + SQLite).

## Что умеет

- Добавлять, редактировать и удалять доходы и расходы (сумма, категория, дата, комментарий)
- Показывать итоги по месяцам: доходы, расходы, разницу и общий баланс
- Строить диаграммы: расходы по категориям и динамику за последние 6 месяцев
- Задавать месячные лимиты по категориям и предупреждать о превышении
- Фильтровать операции по типу и категории
- Выгружать все операции в CSV (открывается в Excel)

## Запуск

```bash
cd finance
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000. Данные хранятся в файле `finance/finance.db`
(путь можно поменять переменной окружения `FINANCE_DB`).

## Тесты
